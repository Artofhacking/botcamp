下载 BotCamp

这是 Windows 安装包。装好后用 phosa@qq.com 登录。浏览器开在你自己的电脑上。

下载 Windows 安装包（BotCamp-Windows-x64-setup.exe）

这次没有 Mac 安装包。Mac 需要在 Mac 上打包，这台构建机做不到。

打开之后

  1. 打开下载的安装包。Windows 如果提示未知发布者，选「更多信息」，再选「仍要运行」，然后安装。
  2. 本机需要已经安装 Google Chrome。
  3. 打开 BotCamp，用 phosa@qq.com 和原来的密码登录。
  4. 点「主编」，再点「查看对话详情」，打开「浏览器」。
  5. 点「导入 cookie」，选「从文件导入…」，选小黑盒账号「小稿的AI日记」的 cookies.txt、JSON，或 Playwright storageState。不是小黑盒域名的 cookie 会被丢掉，内容只留在这台电脑的 Chrome 里。
