下载 BotCamp

装好后用 phosa@qq.com 登录。浏览器开在你自己的电脑上。

  • Windows 安装包
  • Mac（Apple 芯片）
  • Mac（Intel）

打开之后

  1. 安装并打开 BotCamp。Windows 如果提示未知发布者，选「更多信息」再选「仍要运行」。Mac 如果提示无法打开，在应用程序里对 BotCamp 按住 Control 点按，选「打开」。
  2. 本机需要已经安装 Google Chrome。
  3. 用 phosa@qq.com 和原来的密码登录。
  4. 点「主编」，再点「查看对话详情」，打开「浏览器」。
  5. 点「导入 cookie」，选「从文件导入…」，选小黑盒账号「小稿的AI日记」的 cookies.txt、JSON，或 Playwright storageState。不是小黑盒域名的 cookie 会被丢掉，内容只留在这台电脑的 Chrome 里。
