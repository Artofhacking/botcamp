用已经装好的 DSH Desktop

主编在 DSH Desktop 里。不要再装 BotCamp 这个单独的应用。浏览器和这台电脑上的文件用的是 DSH 自己的，不另开一套。

Mac 上已经有 DSH

  1. 按 Command-空格，输入 DSH，打开 DSH Desktop。名字也可能是 DeepSeek Harness。
  2. 或者打开「访达 → 应用程序」，双击同一个应用。
  3. 侧栏点「主编」。账号仍是 phosa@qq.com。

Mac 上还没有 DSH

需要安装的是 DSH Desktop，不是 BotCamp 的压缩包。当前社区安装包是 Apple 芯片（M 系列）的 DMG。Intel Mac 还没有对应的安装包。

  1. 从 dshdesktop.cn 下载 macOS 的 DMG。
  2. 打开 DMG，把 DSH Desktop 拖进「应用程序」。
  3. 第一次如果被拦住：在「应用程序」里按住 Control 点 DSH Desktop，选「打开」。也可以到「系统设置 → 隐私与安全性」里点「仍要打开」。
  4. 打开之后，侧栏点「主编」，用 phosa@qq.com 登录。
