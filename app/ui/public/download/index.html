DSH Desktop 2.0.19

这是带主编的 DSH Desktop，给 Apple 芯片（M 系列）的 Mac。打开后窗口标题是 DSH Desktop 2.0.19，主编旁边也写着同一版本。

下载 DSH Desktop 2.0.19（Apple 芯片）

  1. 下载后双击压缩包，解压出 DSH Desktop。
  2. 把它拖进「应用程序」。
  3. 第一次如果被拦住：按住 Control 点 DSH Desktop，选「打开」。也可以到「系统设置 → 隐私与安全性」里点「仍要打开」。
  4. 用 phosa@qq.com 登录。对话记在共享账本上，关掉再打开还在。

浏览器是这个应用自己打开的窗口。选工作区之后，列文件和读文件只在那个文件夹里。
