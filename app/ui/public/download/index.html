下载 BotCamp

装好后用 phosa@qq.com 登录。浏览器开在你自己的电脑上。本机需要已经安装 Google Chrome。

  • Windows 安装包
  • Mac（Apple 芯片），macOS 11 或更新。
  • Mac（Intel），macOS 11 或更新。

Windows

  1. 打开安装包。如果提示未知发布者，选「更多信息」，再选「仍要运行」。

Mac

  1. 打开 zip，把里面的 BotCamp 拖进「应用程序」。
  2. 如果系统说无法打开，在「应用程序」里按住 Control 点 BotCamp，选「打开」。

登录之后

  1. 用 phosa@qq.com 和原来的密码登录。
  2. 点「主编」，再点「查看对话详情」，打开「浏览器」。
  3. 点「导入 cookie」，选「从文件导入…」，选小黑盒账号「小稿的AI日记」的 cookies.txt、JSON，或 Playwright storageState。不是小黑盒域名的 cookie 会被丢掉，内容只留在这台电脑的 Chrome 里。
