DSH Desktop 2.0.18

这是官方 DSH Desktop 2.0.18 本体，主编加在同一个窗口里。不是 BotCamp，也不是之前那个只有主编、会被系统说成「已损坏」的 2.0.19 窄窗口。

下载 DSH Desktop 2.0.18（Apple 芯片）

打开之后应该看到这些，才能确认是 DSH Desktop：

  • 程序名是 DSH Desktop。Finder「简介」里版本是 2.0.18，标识符是 ai.deepseek.dsh.desktop。
  • 窗口是 DSH 自己的：左侧是会话和工作区侧边栏，中间是 DSH 的对话，里面有 DSH 自己的浏览器。
  • 同一个窗口左下角有一颗蓝色的 主编 按钮。点开后主编浮在这个窗口上，不会换成另一个壳。
  1. 下载后双击压缩包，解压出 DSH Desktop。
  2. 把它拖进「应用程序」。
  3. 第一次按住 Control 点 DSH Desktop，选「打开」。
  4. 用 phosa@qq.com 登录主编。对话记在共享账本上，关掉再打开还在。
