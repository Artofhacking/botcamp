# 钩子库：前 3 秒的 12 种开场

开场不是“第一句话”，是观众愿不愿意给你接下来的 30 秒。下面这些句式按情绪和场景分，拿来改，不要照抄。

> 别一次用三个。钩子叠太多会像广告。一条片子只用一种，剩下两种留给下一条。

## 情绪类

1. **损失感**：“你还在用三年前的方法做今年的内容。”
2. **反差**：“这条视频我拍了三遍，前两遍都是错的。”
3. **共鸣**：“如果你也日更，却越更越没人看。”
4. **好奇**：“一个 300 播放的视频，改了一句话到了 2 万。”

## 场景类

- **通勤**：“如果你每天只有 20 分钟做内容，这条最有用。”
- **新手**：“第一次做口播，先避开这三个坑。”
- **复盘**：“发了 100 条之后，我只留下这三个选题。”
- **对比**：“同样的内容，为什么别人发就有人看？”

## 反常识类

- “不要追热点。热点是给已经有流量的人准备的。”
- “封面不是越好看越好，是越容易在 3 秒内被看懂越好。”
- “日更不是勤奋，是逃避选题。”
- “完播率低，不一定是内容差，可能是开头太客气。”

## 使用说明

选一条，改成你自己的语气，读三遍。读起来不像你说的话，就换一条。钩子库是起点，不是答案。
