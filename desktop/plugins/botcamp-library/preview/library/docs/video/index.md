## 逐字稿

先说结论：**你的内容没人看，不是因为不够努力，是因为前 3 秒没有给出承诺。**

我见过一条视频，拍了三遍，剪辑两版，封面换了五次，播放量还是 300。后来只改了一句话，把它放到开头，播放量到了 2 万。

那句话是：“如果你也在日更，却越更越没人看，这条一定要看完。”

> 承诺不是标题党。标题党承诺的是情绪，内容承诺兑现的是信息。
