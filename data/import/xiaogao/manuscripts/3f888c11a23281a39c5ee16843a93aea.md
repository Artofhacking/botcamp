# 旧手机四步改成小服务器

闲置红米，系统不用动。装个终端，自己的电脑就能连上去。

## 1. 装 Termux

到 GitHub releases 下载 Termux。商店版太旧，源是坏的。

打开后输入：
pkg update && pkg upgrade
pkg install openssh
passwd
whoami
sshd

whoami 打出来的就是后面要用的用户名。passwd 设密码，输入时屏幕不显示字符是正常的。

## 2. 装 Tailscale

手机和电脑都装 Tailscale，登同一个号。手机会得到一个 100 开头的地址。

电脑上连：ssh -p 8022 用户名@100开头的地址

不想每次都输密码：ssh-keygen -t ed25519 然后 ssh-copy-id -p 8022 ...

## 3. 别让手机把后台杀掉

Termux 里打开唤醒锁。再装 Termux:Boot，开机脚本写 termux-wake-lock 和 sshd。小米手机：Termux 省电选无限制，打开自启动，最近任务里锁上。

## 4. 每天只充 4 小时

一直满电，电池容易鼓。买个定时插座（向日葵 C1 Pro，约 15 块），每天 20:00 到 24:00 通电。

连上就能用。跑脚本、存文件、给自己当个小终端，都够。待机电流一百来毫安，电费每月两块左右。
