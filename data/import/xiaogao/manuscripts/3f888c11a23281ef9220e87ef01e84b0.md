# 如何搭建一个个人 AI 助手？大脑和身体是两回事

## 平台
小黑盒

## 正文（可直接复制）

很多人一听“搭建个人 AI 助手”，第一反应就是买服务器、敲命令、装一堆看不懂的东西。其实先不用想这么远。一个 AI 助手拆开看，主要就是两样东西：大脑和身体。大脑是必要的，身体是可选的。

只有大脑，它就和豆包、DeepSeek 最基础的聊天模式差不多：你问，它答。身体则是它能使用的电脑、软件、工具和账号权限。

比如你把 Steam API Key 配置给自己的助手，它就能自己获取你的游戏库；再让它抓取实时折扣，就能按你的喜好推荐游戏。

## 身体还能带来记忆

自己的助手有运行环境以后，可以把聊天记录、偏好和任务存到硬盘或者数据库里。所谓“永久记忆”并不是模型突然长脑子了，只是记录被你自己保存了下来。

如果愿意自己折腾，OpenClaw、Hermes 这类开源框架比较合适。不想折腾，也可以下载 Tavo 这类现成的 AI 聊天前端。

## API 和 Token 又是什么

想让自己的程序使用 DeepSeek、GLM 这些模型，一般就要调用 API。Token 是计费单位。App 的免费额度与 API 按量计费不是同一种消费方式。

现在更推荐拿 GLM-5.3-Flash 跑个人助手。大脑决定它聪不聪明，身体决定它能不能干活，运行环境决定它能不能记住你。
