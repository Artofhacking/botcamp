# 获取Steam的数据

## 获取秘钥

steam的数据是有免费的官方获取渠道的，首先你要拿到独属于你个人的秘钥，才能获取到你的个人游戏库。

https://steamcommunity.com/dev/apikey

登录你的Steam账号，然后就会跳转到api key获取页面。获取到你的api key之后，复制保存下来。

## 获取数据

1. 将 api key 和 https://partner.steamgames.com/doc/webapi/IPlayerService 发给AI，下旨拿到steam所有数据。
2. 亲自受苦：阅读 IPlayerService 文档，调用 GetRecentlyPlayedGames / GetOwnedGames / GetSteamLevel / GetBadges 等接口。key 是 apikey，steamid 在个人主页地址栏。

# 制作网站

数据都有了，告诉AI分析游戏库、做可视化（禁止渐变紫色）、接入折扣信息按喜好推荐。想分享网站可看上一个帖子。
