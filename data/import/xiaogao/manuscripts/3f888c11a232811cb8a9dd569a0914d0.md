# 一个免费的数据库+后端

带登录、还要存数据的小网站，别先买服务器。推荐 Supabase。一个免费的数据库，后端也顺便有了。个人项目可以一个月 0 块。

页面放 Cloudflare Pages，用户和数据放这。

注册登录不用自己写。邮箱、Google、GitHub 都能接，免费版 5 万月活。数据是 Postgres，一个项目 500MB。图片和日志别往里倒。

查数据也不用再写一套接口。前端直接问它。官网写 API 请求次数不限，库满了、流量超了照样卡你。

数据一变，页面还能自己刷新。免费版大概同时 200 人连着，一个月 200 万条消息。

说到坑。免费项目一周没什么访问会暂停。同时只能开 2 个。自带的验证邮件别用，换 Resend。备份也没有。它也不是网盘——图片 PDF 放 Cloudflare R2。

Cloudflare Workers 的默认域名国内打不开，后端别放那。

这东西解决的就是一件事。别为了一张用户表，先去买一台服务器。
