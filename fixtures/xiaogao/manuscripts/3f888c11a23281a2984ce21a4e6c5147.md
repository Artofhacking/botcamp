# 为什么 Cloudflare 被称为“赛博佛祖”？

Cloudflare 明明是个商业公司，免费给的东西却多得有点离谱。DNS、CDN、HTTPS、DDoS 防护，很多东西不掏钱就能用。

## Cloudflare 是干什么的

你可以把它理解成网站门口的一层中转：别人打开你的网站，会先经过 Cloudflare，再到你的服务器。

## 到底“佛”在哪

一个普通小站用得上的 DNS、CDN、HTTPS 和 DDoS 防护，Cloudflare 都有免费版本。Cloudflare 的网站 DDoS 防护目前不按攻击流量收费。然后它还做了 Pages、Workers 和 R2。R2 不收文件下载产生的流量钱。Project Galileo 和 Athenian Project 还会保护公益和选举网站。

## 免费这么多，钱从哪来

靠真正用大了的人挣钱。小网站先用免费版，真把业务做大了，需要更多用量、高级安全规则或者企业支持，钱自然也就交上了。

公有云：你买多大的机器？
Cloudflare：网站不火不收钱。
