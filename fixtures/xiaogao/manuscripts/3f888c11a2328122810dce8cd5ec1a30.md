# 【个人开发日记4】0成本运营一个完整的线上服务

Source: https://app.notion.com/p/3f888c11a2328122810dce8cd5ec1a30

上次聊了怎么免费把网站发布出去，这次聊聊怎么0成本运营一个完整的线上服务。

发布静态页面只是第一步，真正的服务得有用户系统、数据库、文件存储，挂了你要知道，报错你要看得见。以前这一套得租服务器、雇运维，现在各家的免费额度凑一凑，个人项目基本够用了。

先列一下需要哪些东西：

0、网站本体（前端+后端接口）1、数据库2、缓存3、对象存储（用户上传的文件）4、邮件服务（注册验证、通知）5、监控告警（挂了要知道）6、错误追踪（报错要看得见）7、定时任务（定期清理、跑批）8、统计分析（看看有多少人在用）

主包一个个教你免费拿下。

1. 部署：Cloudflare

Pages管静态页面，免费额度每天10万次请求，个人项目用不完。CDN、HTTPS证书、DDoS防护全免费。pages.dev国内可以访问但慢，有域名的话建议套自己的域名。

2. 后端+数据库+认证：Supabase

https://supabase.com/

Cloudflare 的 Workers 国内访问不了，后端建议直接用Supabase。免费版500MB Postgres，50,000月活用户的认证额度。它不只是数据库，基本上把后端都包了：用户注册登录、数据库自带REST API、行级安全策略、实时订阅。

免费版限制：项目7天不活跃会暂停（点一下就恢复），数据库500MB，带宽5GB/月。

3. 缓存：Upstash Redis

https://upstash.com/ 每天10,000次命令免费。缓存只加速，挂了主业务还能跑。登录态别只放Redis。region选新加坡。

4. 对象存储：Cloudflare R2

免费10GB存储，每月100万次读写。零出口流量费。

5. 邮件：Resend

https://resend.com/ 每天100封免费。有自己的域名记得配SPF/DKIM。

6. 监控：UptimeRobot

https://uptimerobot.com/ 免费50个监控点，5分钟检查一次。

7. 错误追踪：Sentry

https://sentry.io/ 免费版每月5,000个错误事件。

8. 统计：Cloudflare Web Analytics

免费，不用Cookie。PV、UV、来源、设备类型够用。

9. CI/CD、定时任务：GitHub Actions

免费版每月2,000分钟。

整体架构：用户浏览器 → Cloudflare Pages → Supabase → Upstash Redis → Cloudflare R2；辅助 Resend / UptimeRobot / Sentry / Web Analytics / GitHub Actions。总成本：0元/月。

免费意味着有限制：Supabase 500MB、Upstash每天1万命令、Resend每天100封、Actions每月2000分钟。个人项目、MVP验证够用。
