# 什么是域名？买了它，网站就有了吗？

很多人第一次接触建站，脑子里的流程大概是：买个域名，往上一绑，网站就上线了。主包先泼一点冷水：没这么简单。

域名只是网站的一部分。它更像是一个好记的门牌号，网站本身还在服务器里。中间还要靠 DNS。

## 域名到底是什么

服务器真正使用的地址通常是一串数字。域名就是给人记的名字，IP 地址是机器找服务器用的地址。

## 浏览器输入网址后，发生了什么

输入域名 -> DNS 查询 -> 找到 IP -> 连接服务器 -> 返回网页

DNS 可以理解成互联网的电话簿。域名、DNS、服务器不是一回事。

## www.baidu.com 怎么拆

.com 是顶级域；baidu.com 是实际注册和持有的域名；www 是它下面的一个子域名。api、admin、test 也可以是同一个主域名下的子域名。

## 买域名，买到的是什么

买到的不是一个网站，也不是一台服务器。买到的是一段时间内使用这个域名的权利。注册商、DNS 服务商和服务器可以不是同一家。

## 为什么买了域名，还是打不开

因为“有门牌号”和“门后面有房子”是两件事。至少要满足：正确的 DNS 记录、服务器上确实有网站、必要时配置 HTTPS。

## 备案和域名在哪买，是一回事吗

不是。是否涉及备案，主要看服务器所在地区和服务情况。

## 总结
域名是人方便记的名字，不是网站本身；买域名只是拿到了一个名字。
