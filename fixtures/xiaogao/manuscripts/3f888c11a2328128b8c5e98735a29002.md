# Cloudflare 为什么被叫“赛博菩萨”？

一个把 DNS、CDN、HTTPS、防 DDoS，甚至网页托管和代码运行都往免费套餐里塞的公司，按理说应该很快破产。可 Cloudflare 不但没破产，还越做越大。

Cloudflare 确实给了很多能用的免费基础服务，但它也不是靠爱发电，而是把免费当成入口：先让个人开发者和小团队接进来，等需求变复杂、流量变大，再卖更高级的功能和服务。

## Cloudflare 到底站在哪

你可以把它想成网站门口的一位总管：DNS、CDN、HTTPS 和基础的 DDoS 防护。Cloudflare 经常站在“访客”和“网站服务器”中间。

## 那它靠什么赚钱

免费用户带来入口和规模。免费层降低进入门槛，付费层负责赚钱。

## 菩萨也有边界

免费不等于无限。主要面向国内用户的网站，更要拿真实网络实测。

Cloudflare 不是不赚钱，只是没有在你的网站还没长大时，就先站在门口收过路费。
