# 做个网页，为什么不一定要先买服务器？Cloudflare Pages 讲明白了

很多人做完一个小网站，第一关不是代码，而是怎么让朋友点开。Cloudflare Pages 干的事，说白了就是帮你把网页文件放到公网。它更像一个对外营业的网页展台，不是一台你可以随便登录进去折腾的电脑。

适合个人主页、作品集、活动页和各种前端小工具。但它也有边界：登录、数据库、支付这些后端功能不会自动出现。pages.dev 地址能不能让目标用户稳定打开，要看网络环境。

# R2 最反常识的地方：文件有人下载，出口流量却不收费

用户上传的 PDF、图片和网页包，先别往服务器硬盘里塞。Cloudflare R2 最容易让开发者记住的一条规则是：数据直接从 R2 传到互联网，不收出口流量费。当然存储容量、读写请求等仍然可能计费。它也不是数据库。

# AI 说“把后端丢 Workers”，它到底把代码丢哪了？

Workers 更像是“有人请求时，Cloudflare 临时替你跑一小段代码”。这就是 Serverless。适合做接口、鉴权、简单的数据处理。workers.dev 对主要面向国内用户的项目并不适合作为稳定入口。

# CDN 不是加速按钮：为什么开了 Cloudflare 还是可能慢

CDN 会把适合缓存的内容放到离访问者更近的节点。登录、订单查询、实时数据通常不能简单地当成一张图片缓存。缓存带来速度，也带来“旧内容什么时候消失”的新问题。
