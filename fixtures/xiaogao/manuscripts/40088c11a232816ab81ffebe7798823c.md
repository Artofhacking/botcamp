# 稿子：便宜服务器怎么挑，连白嫖的也算上（已审通过）

Source: https://app.notion.com/p/40088c11a232816ab81ffebe7798823c

评论区问得最多的一句：「请问99一年在哪买啊」。

先说结论：阿里云、腾讯云、华为云都有百元左右一年的入门服务器。与其记哪家哪个页面，不如学会看这四样：价格、续费、配置、地域。

## 1. 先看清：这个价是谁能买
新人价 vs 新老同享价。

## 2. 重点：续费价
新人价大多只管第一年。阿里云「99计划」活动期内每年能按 99 续一次（到 2029-03-31，以官网为准）。

## 3. 配置：几核几G够用
1核1G / 2核2G（入门最常见）/ 2核4G。硬盘入门款一般 40G。

## 4. 带宽和流量
3M 起步够个人小站。注意限不限流量。

## 5. 地域：选离用户近的

## 6. 国外大厂的免费额度
GCP / OCI / AWS 都有免费额度，要绑卡，适合练手。

## 7. 到底要不要买
只是静态页面可以先不买。需要一直开着跑的东西才真的需要服务器。

一句话：只是放网页，先别买；真要一台，先看续费价，再挑 2核2G、离你近的地域。
