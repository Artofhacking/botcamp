# 从买服务器到 Serverless：部署为何变轻了？

在很久很久以前，部署一个网站是很奢侈的事。你得先买一台大大的服务器。这就是最早的自建服务器时代。

后来，亚马逊把多出来的能力租给别人，推出了 S3，之后 EC2。网站部署从“买机器”，变成了“租机器”。但云服务器不管有没有用户，通常都要一直开着。

于是 AWS 推出了 Lambda。你不用申请一台固定服务器，只要把写好的函数交给它：有人请求，就运行；没有请求，就不占着一台机器等。这就是 Serverless 的核心思路。服务器并没有消失，只是藏在平台后面。

三次变化可以记成一句话：自有服务器是买机器，云服务器是租机器，Serverless 是只交任务，让平台按需找机器执行。
